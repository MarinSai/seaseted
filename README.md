# Seasteads et network states, 1962-2026

Carte du Grand Continent : projets visant à créer des territoires hors de l'autorité des États.

- `index.html` : version française
- `es.html` : versión española
- `it.html` : versione italiana

## Recompiler

```
cd sources
npm install
VITE_LANGUE=fr npx vite build   # puis es, it ; sortie dans dist-<langue>/index.html
```

Source des données : Groupe d'études géopolitiques.
